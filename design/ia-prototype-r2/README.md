# 离线可点击流程原型

解压后打开 `index.html`。不需要 npm、安装、服务或联网。也可以先打开 `review.html` 看前后结构对比与来源。

所有数据均为虚构。原型不会访问现有 Electron 的账号、Cookie、模板或采集数据，不连接网站或飞书，不提供真实发送。只会在浏览器原型存储中保留演示进度，可通过右上角重置。

建议依次体验：发现与候选 → 创建采集任务 → 安全暂停/停止或正常完成 → 对应批次达人复核 → 选入建联 → 仅准备不发送 → 导出或模拟飞书交接。默认从已采集的8人复核样本开始，便于直接评审核心页面。

功能去向、研究来源、设计取舍与未实现的业务契约见 `DESIGN.md`。A为可操作状态、B为辅助示意、C为待接入契约；不代表真实功能已验收。

自动化验证脚本在 `checks/` 中，需要本机已有 Playwright 与 Chrome；默认不会下载或安装依赖。

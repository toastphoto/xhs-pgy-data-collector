# R3 原型方向评审

2026-10-16；分支 `design/toast-2-task-flow-prototype`。双击附件 HTML 即可离线操作，无需安装。仅使用虚构数据，状态独立保存在 `pgy-ia-prototype-r3`；右上角重置可恢复初始数据。

## 本轮变化

- R2 的情境浏览器改为默认同屏核心工作区：名单、详情、网页并列；可隐藏、继续浏览、拖宽和键盘调宽。窄屏上下排列，表格在局部滚动。
- 所有按钮取消蓝色，统一暖白、炭灰和克制暖色强调。表格保留比较字段，资料与操作进入详情。增加选中、禁用、焦点及减弱运动状态。
- 网页模拟支持人工登录标记、分类/粉丝筛选、分页、主页/笔记、后退前进、独立角色及浏览位置；隐藏、切页和刷新后仍可继续。邀约角色同屏展示模拟表单，仅准备不发送。
- 100 行虚构资料分两个来源批次，各 50 人；资料库 100 不等于允许单批采集 100。实际模拟采集仍限制 50、串行推进，保留风险停止与人工检查点。
- 手机加入详情、编辑和联系方式判断。导出增加完整资源 CSV，包含来源、手机、邮箱、微信、报价、初筛、跟进和备注。AI 测试建档明确入口，首次模拟创建前展示 `[AI测试]` 与批次号；正式建档、补录及测试维护仍分开。

## 审查修复与复验

1. P2：下拉切批、历史、概览及采集完成快捷入口统一撤销旧准备和审批。复现“两人已准备→新一人任务→快捷复核”，旧准备失效且清空。
2. P2：筛选、切批同步详情；空列表清空操作；编辑提交再次核对对象及范围，旧对象不能继续修改。
3. P2：排除候选即使被勾选，也须额外确认具体对象才能入队；默认勾选范围不能绕过。
4. P3：导出人数按当前范围；飞书按当前计划；跳过不计已保存。保存手机后恢复同一行键盘焦点和列表滚动。

Chrome 离线自动检查通过 14 组场景，覆盖上述流程、100 行、浏览器继续、鼠标/键盘调宽及 1600/1280/1100/840/390 宽度。控制台错误 0，HTTP 请求 0。检查脚本与 JSON 随证据包提供；没有运行全套业务回归。

## 原生 BrowserView 接入契约（尚未验证）

当前网页区域是 HTML 交互模拟，不是原生 BrowserView、真实蒲公英页面或会话保留证据。无外链、iframe、真实账号和网络请求。

接入时保留原有同一个允许域 WebContents，显隐仅改变可见性及 bounds，不销毁重建或复制 Cookie；受保护搜索页不得被详情/补联/邀约覆盖，各角色沿用原 partition。网页位置、筛选和历史由原网页保持。布局须把分隔条、窗口缩放、DPI/zoom、最小宽度和原生坐标统一换算；弹窗覆盖、焦点、IME、自动化锁和安全停止须在原生层单独验证。不得用这个离线模型证明登录、采集或真实未发送准备可用。

## 取舍与验证范围

让网页默认可见，恢复核心工作台语义；代价是列表变窄，因此允许收起详情/网页、调宽和局部滚动。来源批次与项目资料库分开，跨来源名单要求重新选择批次，避免旧准备误用。离线原型使用单文件原生 HTML/CSS/JS，未引入第三方依赖或复制产品代码。

R2 原文件保留作为前后比较与回退；本轮仅新增 R3 设计文件和记忆。当前源码版本 0.1.96，主进程、preload、renderer 与 lib 哈希未改变。源码业务、开发态 Electron、原生 BrowserView、安装版、真实账号、飞书写入和发送均未在本轮验收。先供面包方向评审及审查员定向复验，通过后再安排业务接入。

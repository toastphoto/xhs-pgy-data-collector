## 目标与边界

采集/补采/本地编辑先落本地；只有明确勾选并执行批量同步才写表。补采后显示待同步差异，不自动改云端。同步不能触发邀约、通知、工作流推进、旧飞书项目迁移或删除。最终邀约发送不在本目标测试范围内。

验收不是“零bug”承诺：必须有精确安装包、每版测试器和真实测试表往返证据，失败/未测项明列。

## 版本与实现方式

建议分支名`codex/feishu-bitable`，基线审阅后再实际创建。先固定已使用版本的源码/产物清单，逐项承接已有修复；不把未验的112整套界面改造混进本次云端替换。

原工作树不动。独立worktree不会自动包含暂存、未提交和未跟踪实现，必须按审阅清单迁入必要源码并核对哈希；禁止只从旧HEAD开空分支就宣称功能保留。源提交、推送和发布另行授权。

多维表格版使用独立安装身份、快捷方式、卸载项、用户目录、会话、单实例锁和后端端口。不能仅改EXE名字而覆盖原版。首版独立登录，不静默复制Cookie或凭证；需要带走旧采集结果时走显式导入，不默认搬整个profile。

新增独立`bitable`连接/字段映射/同步模块与IPC入口；共享已有规范化、报价、复核数据投影和本地保存能力，避免复制整套飞书项目权限/工作流逻辑。新分支启动与后台必须零飞书项目业务请求；旧版凭证不删、不转换成新凭证。

## 表结构建议

一个团队可管理的多维表格，先设两张业务表，字段覆盖清单在实现前冻结：

| 表 | 粒度 | 主要内容 |
| --- | --- | --- |
| 达人资料 | 一个已核实的平台账号一条 | 昵称、主页显示的小红书号、蒲公英/小红书链接、地区、标签、粉丝、图文/视频平台价、微信/邮箱/手机、未分类联系方式及来源、采集时间、最后同步时间、来源批次 |
| 经纪人跟进 | 同一达人和同一经纪人一条 | 关联达人、现维护经纪人、渠道、跟进状态、实际建联时间、备注；同达人不同经纪人可各自建档 |

常用阅读/互动等指标继续按现有采集字段映射，不允许再次退化成只存昵称和主页。嵌套粉丝统计/笔记明细先盘点实际结构，再明确扩展字段或关联明细表；未映射字段必须列明，原始采集结果留本地，不默默丢弃或上传含敏感信息的原始响应。

小红书号按文本保存，不能当数值损坏前导零；PGY ID、XHS主页ID、主页显示的小红书号分别记录，不能互当。身份不完整可保存待核实资料，但不得凭同昵称合并他人记录；补齐身份后显式核对关联。

联系方式允许空，未分类值保持原样；明确“暂未报价”按既有规则为0，读取缺失/解析失败不冒充0。采集入库不等于已建联，入库时间与实际建联时间分开；同步不伪造“已邀约”。

经纪人沿用“本人输入/选定并记住”的交互，使用新的飞书人员标识或经审核的成员映射，不默认取应用操作者、不复用项目User Key、不把同名第一项当唯一人员。无经纪人不阻断达人资料入库，仅跟进记录等待选择。

## 同步与冲突规则

- 连接确认一次目标表和授权范围；每批显示明确人数、目标表、新增/补充/不变/冲突结果，一次批量确认，不逐人反复审批。同步勾选独立于邀约和导出列勾选，不暗中同步未选中或筛选外的人。
- 达人资料按已核实身份关联，跟进按达人加经纪人查重。重复点击、重复导入不新增重复跟进；不同经纪人不相互覆盖。云端同人多条存在歧义时让用户选目标。
- 首次入库写允许字段；后续只更新明确变化的业务字段，空值不清除云端非空联系方式。保护人工备注、经纪人归属及跟进状态；人员或目标错误才阻断，不因创建者/更新者或毫秒时间差拒绝正常补录。
- 从表中回补联系方式保留，先匹配账号和来源，明确冲突后批量应用；未知联系类型不猜成微信。暂不做所有字段双向无条件覆盖。
- 保存持久同步编号、目标表/记录ID、已提交内容和逐行结果。状态至少包括待同步、处理中、已同步、失败、结果待核对、已停止；停止后不再派发新行，已发出的请求先核对结果。
- 断网/限流不丢本地结果；成功行不重发。写入返回未知时先精确查询，不能换一个请求编号盲目重建。客户端幂等参数的适用接口/保留期在开发时逐项核实，不假设永久业务唯一。
- 多电脑并发是单独风险：本机串行加先查后写不能保证跨电脑唯一。先验证平台幂等/冲突行为；需要严格唯一时使用团队单写入协调服务。交付前明确部署选择并实测双客户端，不声称单机通过等于团队并发通过。

## 授权与表归属

飞书项目插件与飞书开放平台多维表格应用是两套接入。需确认企业自建应用/授权方式、团队表归属和应用访问该表的权限；现有项目连接字段不能直接替换使用。

优先让表归团队可管理的用户/位置，再赋予应用必要数据权限，避免“应用建表成功但同事不能编辑”。应用凭证不写进Git、安装包或截图；桌面凭证仅走本机加密存储。团队共享密钥不通过复制配置散发；若采用应用身份与集中写入，凭证由受控服务保管，部署和每位同事认证在接入阶段确认。

6. **真实验收与交付：待做。** 在精确安装版完成真实测试表新增/读取/修改/回补；重复批次、同/不同经纪人、缺联系方式、未报价、断网恢复、结果未知、两客户端并发分别验。采集/补采/连续三位未发送邀约准备/品牌/导出/拖宽/旧任务停止回归；通过后提供独立Windows安装包、测试报告、配置与使用说明。

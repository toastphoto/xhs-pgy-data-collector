## 映射风险

| 页面字段 | 当前观察 | 接入要求 |
| --- | --- | --- |
| 平台、来源 | 默认小红书、主动搜索达人资源 | 读取选项值，不能按文字或默认值猜 API 枚举 |

| 覆盖结果、建联次数 | 默认尝试建联、1次 | 新建预览必须核实；导入线索本身不等于联系过一次 |

昵称与其他备注的字段映射只是 DOM 线索；字段类型、条件必填、权限和选项最终以授权元数据及受控回读为准。API 元数据返回顺序不保证等于表单顺序。

## 官方接口依据

- [Open API 概述](https://project.feishu.cn/b/helpcenter/1p8d7djs/4bsmoql6)：需要 `X-PLUGIN-TOKEN`。使用插件凭证时配合 `X-USER-KEY`；用户凭证是另一条授权路径。插件凭证只读查询采用 `x-auth-mode: 1`，不通过兼容模式扩大用户可见范围。写接口可用 `X-IDEM-UUID`，文档限定同凭证、同接口，不能据此保证跨凭证刷新或永久去重。
- [获取访问凭证](https://project.feishu.cn/b/helpcenter/1p8d7djs/4id4bvnf)：插件凭证由 Plugin ID / Plugin Secret 获取；开发调试有受数据范围约束的虚拟插件凭证。用户登录 Cookie、项目 key、工作项类型 key 都不能直接替代上述凭证。认证接口用 `error.code`，业务接口示例用 `err_code`，客户端不可只检查 HTTP 状态或混用结构。
- [获取创建工作项元数据](https://project.feishu.cn/b/helpcenter/1p8d7djs/2jhqmwhn)：`GET /open_api/:project_key/work_item/:work_item_type_key/meta`。返回布局配置中的字段、默认值、选项和必填/条件必填等属性；未配置进布局的字段不一定返回。
- [复杂条件查询](https://project.feishu.cn/b/helpcenter/1p8d7djs/19pti4e2)：`POST /open_api/:project_key/work_item/:work_item_type_key/search/params`。每页最多 50，匹配超过 5000 报错；不能靠分页绕过总匹配限制。按同平台稳定标识分组精查，不默认全库拉取。
- [删除工作项](https://project.feishu.cn/b/helpcenter/1p8d7djs/2f5xepox)：`DELETE /open_api/:project_key/work_item/:work_item_type_key/:work_item_id`，删除一个工作项实例，需独立权限。官方存在接口不证明当前账号可调用，也未证明删除可恢复。

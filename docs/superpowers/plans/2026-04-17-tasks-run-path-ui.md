# Tasks Run Path UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在「批量任务」页显示 `runId/runDir`，并提供“一键打开本次运行目录 / runs 总目录”按钮，方便进入导出阶段。

**Architecture:** Renderer 从 `tasks:state` 中读取 `runId/runDir` 展示；点击按钮走 preload → IPC → main 使用 `shell.openPath(...)` 打开目录。

**Tech Stack:** Electron main/preload/renderer（vanilla JS）。

### Task 1: Main 新增打开目录 IPC

**Files:**
- Modify: `desktop-app/main.js`

- [ ] **Step 1: Add handlers**

Add near existing `tasks:*` handlers:

```js
ipcMain.handle('tasks:openRunDir', async () => {
  if (!taskRunner) return { ok: false, error: 'taskRunner 未初始化' };
  const dir = taskRunner?.state?.runDir || '';
  if (!dir) return { ok: false, error: 'runDir 为空' };
  try {
    const r = await shell.openPath(dir);
    return r ? { ok: false, error: r } : { ok: true, dir };
  } catch (e) {
    return { ok: false, error: String(e?.message || e) };
  }
});

ipcMain.handle('tasks:openRunsDir', async () => {
  try {
    const dir = getRunsDir();
    const r = await shell.openPath(dir);
    return r ? { ok: false, error: r } : { ok: true, dir };
  } catch (e) {
    return { ok: false, error: String(e?.message || e) };
  }
});
```

- [ ] **Step 2: Syntax check**

Run:
```bash

```

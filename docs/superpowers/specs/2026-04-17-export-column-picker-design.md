# 二次导出：按列勾选（精简版资源表）设计

## 目标

在「结果&导出」页提供“二次导出（按列勾选）”能力：

1) 基于已生成的“媒介资源表（达人一行）”列体系，提供勾选 UI  
2) 用户勾选后导出“精简版”Excel  
3) **保留规则：先按勾选列，再自动移除“全空列”**（用户选择 A/“要”）  
4) 记住上次选择（本机持久化）

## 用户故事

- 我已经导出全量资源表，但对外/对内场景需要不同字段组合  
- 希望在 App 内快速勾选要的列，并产出一个新的 Excel（精简版），无需手工在 Excel 里删列

## 功能范围（v1）

### 入口与页面

位置：`结果 & 导出` 页

新增模块：**二次导出（按列勾选）**

包含：
- 当前 run 选择下拉（沿用已有）
- 列搜索框（按列名包含匹配）
- 操作按钮：全选 / 全不选 / 反选 / 恢复默认（可选）
- 分组展示（折叠/展开可选，v1 可平铺 + 分组标题）
- 导出按钮：`导出精简版（按勾选列）`

### 列来源

- 以代码中“资源表导出列定义”为唯一来源（避免从已导出文件反读）
- 列分组规则（基于列名前缀/固定列表）：
  - 基础信息
  - 报价
  - 数据概览
  - 粉丝分析
  - 笔记 Top10（从 `笔记1-标题` 开始的所有列）

### 导出规则

输出文件：
- `媒介资源表_<runId>_精简版.xlsx`（保存到对应 runDir）

导出过程：
1) 取用户勾选列列表（按 UI 顺序）
2) 在这些列中执行“全空列剔除”
3) 使用与全量资源表一致的样式导出（表头 2cm、冻结首行、筛选、列宽/换行、笔记区浅黄底）

### 记忆规则

- 将勾选结果保存到本机（userData）配置：按列名数组保存
- 下次进入页面：
  - 若列名集合与当前版本一致 → 直接恢复
  - 若有新增列 → 新列默认勾选（或默认不勾选；v1 采用“默认勾选”，避免漏字段）
  - 若列被移除 → 忽略

## IPC/数据流

- renderer 调用 `exports:getResourceColumns` 获取列定义 + 分组信息
- renderer 保存选择到本机：`exports:saveColumnPreset` / `exports:loadColumnPreset`
- renderer 调用 `exports:exportResourceRun`（新增参数 `selectedColumns`）生成精简版

## 验收标准

- 能在 UI 勾选/取消列，并导出精简版 xlsx
- 精简版只包含勾选列，并自动剔除全空列
- 记住上次选择，下次默认恢复

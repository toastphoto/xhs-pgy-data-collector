# 桌面端 UI 重做：浅色 + 柔和粉（设计）

## 目标

将当前偏“开发工具感”的深色 UI，升级为更符合**现代办公职场女性**偏好的风格：**浅色底 + 柔和粉强调色**，并重点解决：

1) 视觉“丑、挤、信息糊在一起”
2) 导出页「列勾选」区域可读性差、密度过高
3) 不改业务逻辑（采集/导出/队列功能保持不变）

## 设计原则

- **轻量改造**：优先修改 `renderer/app.css` 与少量页面结构（exports/tasks），不引入重型框架
- **可读优先**：字号与行高更舒适，信息分组更清晰
- **统一组件**：按钮/输入框/卡片/标签统一视觉语言
- **对比度合规**：文本颜色与背景对比足够（避免“看不清”）

## 视觉规范（Design Tokens）

### 颜色

- 背景（App）：`#FAFAFB`
- 面板/卡片：`#FFFFFF`
- 分割线：`#E7E8EE`
- 主文本：`#111827`
- 次文本：`#6B7280`
- 主要强调色（柔粉）：`#E85A9A`
- 强调浅底（柔粉背景）：`#FFE4F0`
- 轻阴影：`0 8px 24px rgba(17, 24, 39, 0.08)`

### 字体/排版

- 基础字号：14px
- 标题：16–18px
- 行高：1.5–1.7
- 圆角：12px（卡片/输入），10px（按钮）

### 间距体系

统一使用：8 / 12 / 16 / 24（避免“挤”）

## 信息架构与布局

### 顶部栏 Topbar

- 左：当前模块标题（更明显）
- 中：浏览器地址栏（输入框更宽、边框更轻）
- 右：后端状态 Chip（浅底色，绿色/红色点缀）

### 左侧导航 Sidebar

- 改为“浅底侧边栏 + 选中柔粉底”
- 每个导航项更高的行高（≥ 40px），避免拥挤
- 文字层级清晰，可选增加小图标（v1 可先不加）

### 内容区 Content

统一使用“卡片分区”：
- 每个页面由多个卡片组成（标题 + 说明 + 操作区 + 结果区）
- 卡片之间留足间距（16px）

## 重点页面：结果&导出（列勾选区重做）

现状问题：列勾选密度过高、三列网格导致横向拥挤、分组不清晰。

### v1 改造方案（两栏筛选面板）

- 顶部：run 选择 + 导出按钮（主次按钮层级）
- 二次导出区域：两栏布局
  - 左栏：分组列表（基础信息/报价&规模/数据概览/粉丝分析/笔记Top10）
  - 右栏：当前分组的列 checkbox 列表（行高更舒适）
- 搜索框：在右栏顶部，支持清空
- 操作条：底部 sticky（显示“已选 X / 总计 Y” + 主按钮“导出精简版”）

### 交互细节

- Checkbox 触控区域扩大（整行可点）
- 主按钮使用柔粉强调色；次按钮为描边/浅底
- 保留现有规则：**先按勾选列 → 再自动剔除全空列**

## 实施范围（文件）

**主要修改：**
- `desktop-app/renderer/app.css`：引入浅色主题 token + 组件统一样式
- `desktop-app/renderer/app.js`：必要时调整结构类名（尽量少改）
- `desktop-app/renderer/views/exports.js`：重排列勾选 UI（两栏+sticky 操作条）

**尽量不改：**
- 主进程采集/导出逻辑

## 验收标准

- 全局：字体可读、间距不挤、主次层级清晰
- 导出页：列勾选区不再拥挤；分组清晰；可在 1 屏内完成“选择→导出”
- 不影响：采集、批量任务、导出功能可用
